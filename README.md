# Kingdom Life Church Website

Welcome to the official website of **Kingdom Life Church**. This project is a responsive, modern, and user-friendly website built using **HTML**, **CSS**, **Bootstrap 5**, and **JavaScript**. It showcases the church’s ministries, sermons, events, and contact information.


## Table of Contents

- [Features](#features)
- [Technologies Used](#technologies-used)
- [Project Structure](#project-structure)
- [Setup](#setup)
- [Contributing](#contributing)
- [License](#license)


## Features

- Responsive design for mobile, tablet, and desktop
- Navbar with dropdown menus for ministries
- Sermons section with embedded Facebook videos
- About section with mission, vision, and values
- Contact section with clickable phone and email links
- Footer with social media links and quick navigation
- Smooth scrolling for a seamless user experience


## Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive layout
- **Bootstrap 5** – Grid system and components
- **JavaScript** – Interactivity and animations
